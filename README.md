# TaskFlow Dashboard

A modern Task & Project Management Dashboard built with React, Vite, Tailwind CSS, and Recharts.

## Features

* User Authentication UI (Login/Register)
* Project Management Dashboard
* Task Creation & Status Tracking
* Analytics Dashboard with Charts
* Responsive UI for Mobile & Desktop
* Drag & Drop Task Workflow
* Error Handling & Loading States
* REST API Integration Ready
* Clean Component-Based Architecture

---

## Tech Stack

### Frontend

* React.js
* Vite
* Tailwind CSS
* Recharts
* React Router DOM

### Backend APIs

* POST /login
* POST /register
* GET /projects
* POST /tasks
* PATCH /tasks/:id
